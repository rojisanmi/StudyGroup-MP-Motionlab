# Local Storage with Room

## Deskripsi Tugas
Aplikasi ini menggunakan Room sebagai Local Storage untuk menyimpan daftar jadwal (Schedule). Aplikasi ini memiliki fitur CRUD (Create, Read, Update, Delete) yang memungkinkan pengguna untuk menambahkan, melihat, mengedit, dan menghapus jadwal yang tersimpan di penyimpanan lokal.

## ✨ Fitur Aplikasi
- **Tambah Jadwal**: Pengguna dapat menambahkan jadwal baru dengan memasukkan nama dan tanggal.
- **Lihat Jadwal**: Menampilkan daftar jadwal yang telah disimpan dalam database lokal.
- **Edit Jadwal**: Pengguna dapat memperbarui informasi jadwal yang telah dibuat.
- **Hapus Jadwal**: Pengguna dapat menghapus jadwal yang tidak diperlukan.

## 🚀 Cara Menjalankan Aplikasi
### 1. Menambahkan Jadwal
- Klik tombol **Tambah (+)** pada halaman utama.
- Masukkan nama dan tanggal jadwal.
- Tekan tombol **Simpan** untuk menambahkan jadwal ke daftar.

### 2. Mengedit Jadwal
- Pilih jadwal yang ingin diedit dari daftar.
- Ubah nama atau tanggal jadwal sesuai keinginan.
- Tekan tombol **Simpan** untuk menyimpan perubahan.

### 3. Menghapus Jadwal
- Pilih ikon **Hapus (🗑️)** pada jadwal yang ingin dihapus.
- Jadwal akan dihapus dari daftar.

Aplikasi ini dibangun menggunakan Kotlin, Jetpack Compose, Room Database, dan LiveData untuk memastikan data tersimpan dengan baik dan ditampilkan secara real-time.
